# Watermelon Propostas

Site comercial simples para apresentar experiências da **Watermelon Experiences** e montar propostas personalizadas para clientes.

## Objetivo

- catálogo de experiências;
- páginas individuais;
- seleção de várias experiências;
- criação de proposta com cliente, data, participantes, preço e observações;
- partilha por WhatsApp;
- impressão / guardar em PDF;
- preparado para publicação na Vercel.

## Segurança

Não guardar chaves Viator/Bókun no repositório. Qualquer integração futura deverá usar variáveis de ambiente na Vercel.

## Desenvolvimento

```bash
npm install
npm run dev
```

Abrir http://localhost:3000
